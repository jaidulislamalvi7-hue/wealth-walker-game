# 🏆 Wealth Walker

A single-file HTML5 canvas game about collecting wealth — and learning that money isn't everything.

**Play now:** https://jaidulislamalvi7-hue.github.io/wealth-walker-game/

## Features
- 🎮 Canvas-based snake-style gameplay
- 💰 Collect money, gold, diamonds, and donations
- ⚠️ Avoid taxes, thieves, losses, and pandemics
- 🚗 5 vehicle upgrades (Suit → Cycle → Bike → Car → Jet)
- ✨ 3 versions (Metal → Gold → Diamond)
- 🔊 Procedural audio (no audio files needed)
- 📱 Mobile swipe + D-pad support
- 🏆 Local high score via localStorage

## Controls
| Action | Keys |
|---|---|
| Move | Arrow keys / WASD / Swipe |
| Pause | P / Esc / ⏸ button |
| Mute | 🔊 button |

## Tech
Pure HTML + CSS + JavaScript. No dependencies, no build step, no backend.
